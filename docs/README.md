# Account connection

Use Configuration → Connect account. Continue in Iseteenindus, sign in, compare the confirmation code and approve the installation. The pending request expires after ten minutes. Keep the Workspace page open while confirming.

A connected account is separate from paid service coverage. No licence key or installation token needs to be pasted into this integration. Server-side Core configuration must enable the account-link service.

Discovery lists package information; installation is a separate owner action. The package does not register a special catalogue storage source.
